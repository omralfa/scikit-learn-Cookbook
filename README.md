## Chapter Overview

### Chapter 1 — Common Conventions and API Elements of scikit-learn

Membahas dasar API scikit-learn, termasuk estimator, transformer, custom components, pipeline, common API methods, hyperparameter tuning, metadata, dan best practices.

Notebook: `Chapter_1/Chapter_1_Common_Conventions.ipynb`

---

### Chapter 2 — Pre-Model Workflow and Data Preprocessing

Membahas proses persiapan data sebelum modeling, meliputi data cleaning, missing data, scaling, categorical encoding, pipeline, dan feature engineering.

Notebook: `Chapter_2/Chapter_2_Pre_Model_Workflow.ipynb`

---

### Chapter 3 — Dimensionality Reduction Techniques

Membahas dimensionality reduction menggunakan feature selection, feature extraction, PCA, LDA, dan t-SNE.

Notebook: `Chapter_3/Chapter_3_Dimensionality_Reduction.ipynb`

---

### Chapter 4 — Building Models with Distance Metrics and Nearest Neighbors

Membahas distance metrics dan algoritma K-Nearest Neighbors (KNN), termasuk Euclidean, Manhattan, Minkowski, Cosine, evaluasi model, dan hyperparameter tuning.

Notebook: `Chapter_4/Chapter_4_Nearest_Neighbors.ipynb`

---

### Chapter 5 — Linear Models and Regularization

Membahas Linear Regression, Ridge, Lasso, ElasticNet, regularization, bias-variance trade-off, dan polynomial regression.

Notebook: `Chapter_5/Chapter_5_Linear_Models.ipynb`

---

### Chapter 6 — Advanced Logistic Regression and Extensions

Membahas Logistic Regression lanjutan, klasifikasi multikelas, regularisasi, dan pendekatan klasifikasi multilabel.

Notebook: `Chapter_6/Chapter_6_Advanced_Logistic_Regression.ipynb`

---

### Chapter 7 — SVM and Kernel Methods

Membahas Support Vector Machine (SVM), kernel linear dan nonlinear, serta tuning hyperparameter untuk klasifikasi.

Notebook: `Chapter_7/Chapter_7_SVM_Kernel_Methods.ipynb`

---

### Chapter 8 — Tree-Based Algorithms and Ensemble Methods

Membahas Decision Tree, Random Forest, Gradient Boosting, feature importance, dan tuning hyperparameter model berbasis pohon.

Notebook: `Chapter_8/Chapter_8_Tree_Ensemble_Methods.ipynb`
